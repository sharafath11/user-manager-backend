# User Manager Backend

Backend for the full stack user management application.

## Tech Stack

- Node.js
- Express
- MongoDB
- Mongoose
- TypeScript

## API Endpoints

- `GET /api/users`
- `POST /api/users`
- `PATCH /api/users/:id`

## Environment

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
```

## Run Locally

```bash
npm install
npm run dev
```

The server runs on `http://localhost:5000`.
